# DECISION-TREE-STUDENT-STRESS-FACTORS
Repository ini berisi project analisis faktor-faktor yang memengaruhi tingkat stres mahasiswa menggunakan metode Decision Tree. Proyek ini bertujuan untuk mengidentifikasi variabel yang paling signifikan memengaruhi stres dan menyajikan insight yang dapat membantu pihak kampus atau konselor dalam merancang strategi pengurangan stres.

# Fitur Utama:

1. Data Collection & Preprocessing: Membersihkan dan menyiapkan dataset dari survei mahasiswa.

2. Decision Tree Modeling: Membangun model Decision Tree untuk memprediksi tingkat stres dan memahami pengaruh masing-masing faktor.

3. Data Visualization: Visualisasi cabang keputusan dan distribusi data untuk insight yang mudah dipahami.

4. Insight & Recommendation: Menyediakan informasi actionable tentang faktor yang paling mempengaruhi stres mahasiswa.

# Tujuan (Purpose)

1. Memahami faktor-faktor penyebab stres mahasiswa.

2. Memberikan insight visual yang mudah dipahami untuk pihak kampus atau konselor.

3. Mendukung pengambilan keputusan berbasis data untuk strategi pengurangan stres.

4. Mengaplikasikan teknik Data Science dan Machine Learning (Decision Tree) pada kasus nyata.
